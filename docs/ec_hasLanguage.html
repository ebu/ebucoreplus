Property 'Language [ec:hasLanguage]'

dcterms:description
The language associated with an editorial object. A controlled vocabulary based on BCP 47 is recommended. This property can also be used to indicate the presence of sign language (RFC 5646). By inheritance, it applies at the MediaResource, Fragment, and Track levels where language usage is defined. Best practice is to use the most specific level of granularity possible to describe language usage within a MediaResource, including Fragment and Track levels.

Class 'Publication channel [ec:PublicationChannel]'

dcterms:description
A connection through which a consumption device can consume a service, e.g. a cable receiver for linear services on a cable network, an FM receiver for linear audio services, the YouTube.com webpage or the YouTube application on Android for the VoD service YouTube, the BBC iPlayer App on LG Smart-TVs for BBC's VoD, event streaming and live streaming services.
